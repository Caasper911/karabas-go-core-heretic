# Ядро Doom для Karabas Go / Mini / Mini G

[English version](README.md)

Doom для семейства плат Karabas Go (Xilinx Spartan-6 XC6SLX25): софт-процессор RISC-V VexRiscv на 75 МГц исполняет [doomgeneric](https://github.com/ozkl/doomgeneric) (Chocolate Doom), а буфер кадра, палитра, микшер звука, музыка OPL3 и MIDI-синтезатор платы работают в ПЛИС.

| Плата | Файл ядра | Видео | Звук |
|---|---|---|---|
| Karabas Go | `doom.kg` | VGA | I2S ЦАП (PCM5102); MIDI-синтезатор — только на аналоговом выходе |
| Karabas Mini | `doom.kg` | HDMI | HDMI, аналоговый выход (сигма-дельта) |
| Karabas Mini G | `doom.kg` | HDMI | HDMI, I2S ЦАП |

Файл ядра лежит в `src/`. Игровых данных в нём нет: положите на SD-карту свой IWAD (`DOOM.WAD`, `DOOM2.WAD`, `PLUTONIA.WAD`, `TNT.WAD`, shareware-версию `DOOM1.WAD` или [Freedoom](https://freedoom.github.io/)).

Состояние: проверено на Mini G (DOOM II: игра, музыка, эффекты, сохранения). Сборки для Go и Mini на плате ещё не запускались.

## Возможности

- **Скорость:** около 20–30 кадров в секунду в игре (сама игра Doom идёт с частотой 35 тиков в секунду).
- **Видео:** 320 x 200, 256 цветов, удвоено до 640 x 400 в центре 640 x 480 при 60 Гц.
- **Звуковые эффекты:** 8 каналов, микширует процессор, 11025 Гц.
- **Музыка:** OPL3 FM (инструменты GENMIDI из WAD, как в Chocolate Doom) или MIDI-синтезатор платы (SAM2695) — выбор в OSD.
- **Сохранения:** 6 слотов и настройки (`default.cfg`) хранятся в `<каталог WAD>/saves/<имя WAD>.sav` (1 МБ, файл создаёт прошивка; нужна прошивка 26111813 или новее).
- **Управление:** USB-клавиатура, мышь, USB-геймпад.

Пока нет: PWAD (загружается только один IWAD), сетевой игры.

## Как начать

1. Скопируйте `doom.kg` (один файл для Go, Mini и Mini G) в корень SD-карты.
2. Положите WAD в каталог `/doom` на SD-карте.
3. Выберите Doom в меню ядер. В первый раз откройте OSD (**Menu+Esc**) и выберите WAD (**Menu+F1**). Загрузка WAD занимает время (DOOM2.WAD, 15 МБ — около 25 с); при следующем старте ядро само загрузит последний WAD.

«Menu» — клавиша Windows на клавиатуре.

## Меню OSD

| Пункт | Значения | Клавиши |
|---|---|---|
| WAD | файл `.wad` (загружается при старте ядра) | Menu+F1 |
| Music | MIDI / OPL3 / Off | Menu+M |
| Controls | Classic / WASD (см. ниже) | |
| Mouse move | Off / On: мышь двигает ещё вперёд и назад (как в оригинале; Off — только поворот) | |
| Reset | перезапуск Doom | F12 |

## Управление

| Действие | Клавиатура | Геймпад |
|---|---|---|
| Движение, поворот | стрелки (WASD: ещё W / S, A / D — шаг вбок) | крестовина |
| Огонь | Ctrl, левая кнопка мыши | A |
| Действие (двери, выключатели) | пробел (WASD: ещё E, правая кнопка мыши) | B |
| Бег | Shift | C |
| Шаг вбок | Alt (со стрелками), `,` / `.` | |
| Оружие | 1 .. 7, `[` / `]` — предыдущее / следующее | Z / Y — предыдущее / следующее |
| Меню, Enter | Esc, Enter | X, Start |
| Карта | Tab | Mode |
| Сохранить / загрузить | F2 / F3 | |

Кнопки мыши в Classic: левая — огонь, правая — шаг вбок, средняя — вперёд. Работают оба геймпада (кнопки одинаковые). В WASD буквы W, A, S, D, E работают как игровые только вне меню (имена сохранений набираются как обычно); чит-коды с ними в этом режиме не работают.

Остальные клавиши — как в Doom (F1 справка, F5 детализация, F6 быстрое сохранение, F9 быстрая загрузка, F11 гамма, `-` / `=` размер экрана).

## Сборка

Программа процессора — в `src/fw` (xPack riscv-none-elf-gcc 15.2); прошивка ПЛИС собирается в ISE 14.7 (`src/Makefile`: `make rom`, затем `make minig` / `make mini` / `make go`). Устройство, замеры и история — в `docs/PLAN.md`.
